# Justice Guide - Legal Assistant System

## Project Description
This project is a web-based application that helps users find nearby professionals such as lawyers, electricians, plumbers, and drivers based on their location.

## Features
- User Registration & Login
- Search professionals by category
- Location-based filtering
- Simple UI for quick access

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: JSP (Java Server Pages)
- Database: MySQL

## Database Name
legal_assistant

## How to Run
1. Import the database file into MySQL
2. Configure Apache Tomcat server
3. Deploy the project folder
4. Run using localhost
